    Do Superboxu se z tátovy stránky dostanete 5 rychlými kliknutími na první hvězdičku v nápisu, nebo klávesami Ctrl+Alt+Shift+A. PIN je jen pojistka proti nechtěnému otevření. Skutečně chrání až přístupový token k GitHubu, bez kterého nikdo nic neuloží.
